Forecasting Broadway, honestly.

Gradient-boosted models predict next week's gross and the chance a production closes within 8 weeks. They are evaluated on a time-based holdout against simple baselines, retrained every week by GitHub Actions on a frozen data snapshot, tracked with MLflow, and monitored for drift and live error.

      Method

      How the pipeline works

      Training and evaluation

      • Training data is a frozen, numbers-only snapshot of historical weekly grosses (data/snapshots/); new weeks are never added to training.
      • Train before 2023, tune the number of boosting iterations on 2023, test on 2024 onward; the 2020–2021 shutdown is excluded.
      • Baselines: last week's gross, seasonal persistence, logistic regression, and a low-capacity rule.
      • 95% intervals come from paired bootstraps (by week for gross, by production for closing).

      Deployment

      • A weekly GitHub Actions workflow runs the tests, retrains, logs the run to MLflow (artifact), batch-scores the latest week, and commits static JSON.
      • GitHub Pages serves the JSON; there is no server or external host.
      • Code: ml-weekly.yml, forecast.py, nlp_lift.py.
